# benwestlund.com

Portfolio site for Ben Westlund, UX researcher and PhD student in Health Behavior at UNC Chapel Hill.

Static HTML served by GitHub Pages. Each page carries its own inline styles; fonts (Newsreader, Inter) are self-hosted in the repo root. All files live in the root directory.

- `index.html`: home, selected case studies, about, methods, contact
- `work.html`: case studies (TABLE, AI in the Classroom, EchoCare)
- `research.html`: academic research
- `cv.html`: CV, with `Westlund_Ben_CV.pdf` for download
